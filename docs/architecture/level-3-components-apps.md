# Level 3 — Application components

These diagrams zoom into each application. Read the one that matches the change you are making; you rarely need more
than one at a time.

```mermaid

```

A command is intentionally boring: parse options into a typed filter object, call one service, format the result. If a
command needs branching logic, that logic belongs in `packages/core`.

There is no write path here. If an endpoint seems to need one, the data must be fetched or generated by a CLI command
first.

`@smmachine/core` and `@smmachine/utils` are **devDependencies for typing only** here. Importing them from `app/`,
`components/`, `server/` or `lib/` fails `apps/webapp/__tests__/server-code-boundary.test.ts`.

## MCP server (`apps/mcp`)

```mermaid
C4Component
  title Level 3 — Components inside @smmachine/mcp

  Person(agentClient, "AI agent client")
  ContainerDb(store, "SMM data folder", "SQLite / JSON")

  Container_Boundary(mcp, "@smmachine/mcp") {
    Component(entry, "index.ts / bin.ts", "Node.js", "Entry points for smm mcp server start and the smm-mcp binary")
    Component(server, "server.ts", "MCP SDK, stdio", "Starts the stdio server and connects the registration layer")
    Component(registration, "registration.ts", "zod", "Bridges JSON-Schema tool definitions to zod schemas required by the MCP SDK")
    Component(surfaces, "tools.ts, resources.ts, prompts.ts", "TypeScript", "Tool handlers, resource readers and prompt builders")
    Component(reader, "metrics-reader.ts", "TypeScript", "McpMetricsReader composes core services and returns read-only projections")
    Component(guards, "validation.ts, redaction.ts, mcp-logger.ts", "TypeScript", "Input normalisation, secret redaction and operation logging")
    Component(coreServices, "@smmachine/core", "workspace package", "Read services, repositories and Engineering Health orchestrator")
  }

  Rel(agentClient, entry, "Runs or connects to", "stdio / MCP")
  Rel(entry, server, "Boots", "function call")
  Rel(server, registration, "Registers tools, resources and prompts", "function call")
  Rel(registration, surfaces, "Uses definitions from", "function call")
  Rel(surfaces, reader, "Reads metrics with", "function call")
  Rel(surfaces, guards, "Validates and redacts with", "function call")
  Rel(reader, coreServices, "Calls read services", "function call")
  Rel(coreServices, store, "Reads persisted metrics", "read-only")

  UpdateLayoutConfig($c4ShapeInRow="3", $c4BoundaryInRow="1")
```

The MCP server exposes no generation tools. It is a projection of whatever the CLI already persisted, with credentials
stripped by `redaction.ts`.
